# Домашнее задание к работе 4

## Условие задачи

Двум командам (A и B) выпали номера. Право первого хода получает та команда, для которой выполняется условие: только один из выпавших номеров четный. Запишите условие для получения права первого хода.

## 1. Алгоритм и блок-схема
Алгоритм
Начало
Объявить переменные:
- a — номер команды A (целое число).
- b — номер команды B (целое число).
- result — результат (номер команды, получающей ход).

Ввод исходных данных:
- a
- b

Вычислить условие через арифметическое выражение:
- result = (a % 2 == 0) * 1 + (b % 2 == 0) * 2

Логика:
- если a чётное → добавляется 1 (ход у команды A)
- если b чётное → добавляется 2 (ход у команды B)
- если оба чётные → result = 3 (условие не выполнено)
- если оба нечётные → result = 0 (условие не выполнено)

Вывести значение result.

## 2. Реализация программы

```c
#include <stdio.h>
#include <locale.h>
#include <stdlib.h>

int main()
{
    setlocale(LC_CTYPE, "RUS");
    int a, b;
    int result;

    printf("Введите числа\n");
    scanf_s("%d", &a);
    printf("a = %d\n", a);
    scanf_s("%d", &b);
    printf("b = %d\n", b);

    printf("Результат получает та команда, чье число четное\n");
    result = (a % 2 == 0) * 1 + (b % 2 == 0) * 2;
    printf("Ход получает команда %d\n", result);

    system("pause");
}
```

- Введите числа
- 4
- a = 4
- 7
- b = 7
- Результат получает та команда, чье число четное
- Ход получает команда 1
